# Next.js 与 TypeScript 控制台

本阶段围绕设备列表、详情、创建、编辑、删除和分页，理解浏览器、Server Component、API 契约和后端授权边界。

## 学习范围

- TypeScript 类型收窄、React 状态和受控表单。
- Next.js App Router、缓存、刷新和 Server/Client 边界。
- API client、错误码、加载/空/失败状态和并发提交。
- Playwright 浏览器测试、可访问性和性能。
