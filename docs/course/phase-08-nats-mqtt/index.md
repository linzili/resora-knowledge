# NATS JetStream 与 MQTT Gateway

本阶段把项目从同步 CRUD 推进到消息驱动的 IoT 平台。

## 学习范围

- NATS Core、subject、request/reply、queue group 和重连。
- JetStream、durable consumer、ack、重试、死信和重放。
- Outbox、幂等、at-least-once 和顺序取舍。
- MQTT QoS、会话、LWT、设备身份、遥测、命令和回包关联。
