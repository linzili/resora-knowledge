# Resora Knowledge

这是围绕 `resora-go-lab` 持续整理的 Go、Next.js 和 IoT 平台学习知识库。

这里的内容不是零散的 API 摘抄，而是按照同一个项目逐步推进：先理解原理，再实现功能，然后用测试、故障实验和运行证据验证。

## 推荐阅读顺序

1. [系统学习路线](./course/roadmap)
2. [Go 基础与工程化](./course/phase-01-go)
3. [HTTP 与 chi](./course/phase-02-http)
4. [PostgreSQL、pgx、goose](./course/phase-03-database)

后续课程会继续加入 sqlc、OpenAPI、Next.js、Protobuf、Connect RPC、NATS JetStream、MQTT Gateway 和部署实践。

## 每节课的完成标准

- 能用自己的话解释核心模型和生命周期。
- 在 `resora-go-lab` 中完成一个真实项目切片。
- 同时覆盖成功路径、失败路径和取消/超时语义。
- 运行真实依赖并记录测试、日志或 Trace 证据。
- 记录技术取舍、风险、回滚方式和仍未解决的问题。
